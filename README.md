# Питомцы Twitch: каталог автора

## Один раз
1. В своём аккаунте GitHub создай публичный репозиторий с основной веткой main (например, chibi-pets). Загрузи содержимое комплекта в корень. Файл build.py и папки pets, viewer, .github должны лежать рядом. Если веб-загрузчик пропустил скрытую папку, через Add file → Create new file создай .github/workflows/catalog.yml и вставь содержимое из комплекта. Можно также загрузить через GitHub Desktop.
2. Settings → Pages → Build and deployment → Source → GitHub Actions. В разделе Actions должны быть разрешены workflows. Открой Actions → Publish pet catalog → Run workflow → main. Дождись зелёной отметки. Ссылка на сайт показана в Settings → Pages.
3. На опубликованном сайте кнопка скачивает Twitch-Chibi-Pets-Viewer.zip уже с адресом твоего каталога. Именно этот ZIP получают зрители. Им нужно один раз обновить расширение 1.2: распаковать поверх той же папки, нажать перезагрузку на opera://extensions или chrome://extensions, разрешить доступ к сайту каталога, если браузер запросит, и обновить вкладку Twitch. Для новой установки включить режим разработчика и загрузить распакованную папку с manifest.json.

## Добавить персонажа
В pets создай папку с постоянным коротким ID, например keshi. В ней размести pet.json и картинки. Если полный пакет уже есть — скопируй его целиком. Пример минимального pet.json:
```json
{"name":"Кеши","channel":"login_streamera","animations":{"idle":{"file":"idle.gif","ms":4120},"jump":{"file":"jump.gif","ms":1520}}}
```
Поменяй login_streamera на реальный ник, ms — на время одного прохода в миллисекундах. Остальные названия действий и координаты лап есть в pets/hellfox/pet.json. Для новой версии персонажа оставь прежний ID и обнови файлы в той же папке.

Загрузи изменения в main и дождись успешной публикации. Проверка: добавь catalog.json к адресу сайта — там должна появиться запись нового стримера. Зрители получают список при открытии настроек и примерно раз в 5 минут, пока браузер работает. При выборе имени скачивается весь его комплект. В режиме «Питомец канала» это происходит при открытии прямого эфира добавленного стримера. Успешно загруженные файлы сохраняются в браузере; при изменении скачиваются только новые по содержимому файлы.

Адрес сайта нужно сохранить постоянным. Расширение получает с него только описание каталога и картинки. Публиковать изменения может владелец репозитория и соавторы с правом записи. Зрителям нужен только ZIP с сайта.
